Student Management System in C
This is a simple Student Management System written in C. It allows users to add, view, search, and delete student records using file handling.

 Features
 Add Student
-View Students
 Search Student by ID
 Delete Student
 File Handling (data stored in file)

 How to Run
1. Compile the program:
   gcc student.c -o student
2. Run the program:
   ./student

 Sample Output
1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Exit
